# 筹码增量价值协议 V1 勘误 03：可识别的受限置换

状态：`PREREGISTERED_PLACEBO_CORRECTION_BEFORE_OUTCOMES`。

本勘误只使用已物化价格量候选的协变量和日期，不读取任何收益、成交结果或 2023
数据。原协议的 199 次置换、真实统计量超过 99% 分位、Holm 5% 和所有经济门槛均
不变。

## 协变量可行性审计

把 ISO 周、点时行业、市场状态、行业状态和五个价格量五分位做完全笛卡尔分层时，
17,448 个候选形成 17,305 个单元；只有 273 行位于至少两行的单元。该实现会让
98% 以上分数无法置换，安慰剂几乎等于原统计量，因而不是有效的可证伪检验。

不允许因此放宽到跨周或跨行业随机打乱。改用以下固定受限置换：

1. ISO 周、点时行业、市场状态、行业状态必须完全相同。
2. 动量、`ATR/close`、换手、20 日平均成交额和突破幅度分别用该向前折拟合期
   经验分布转为 `[0,1]` 百分位；评价期不得重拟合。
3. 在每个完全相同单元内，按五维百分位的 L1 距离从小到大做确定性贪心最近邻
   配对；单行不配对，最大允许距离固定为 `1.0`。
4. 每次安慰剂对每个配对用由“协议事件、模块、折、置换序号、配对 ID”生成的
   SHA-256 位决定交换或不交换当前模块分数。未配对行保持不变。
5. 重新按原拟合期模块五分位边界计算最高/最低组差。禁止挑种子、重复抽取最有利
   的配对或按收益修改距离。

该设计保持周、行业和状态完全一致，并让价格量替代解释在最近邻内近似相同；若可
交换覆盖仍不足，结论为 `INSUFFICIENT_EVIDENCE`，不能改成无约束置换。
