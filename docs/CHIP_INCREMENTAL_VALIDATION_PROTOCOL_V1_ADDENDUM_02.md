# 筹码增量价值协议 V1 补充 02：原始指标与模块合成

状态：`PREREGISTERED_FEATURE_FORMULAS_BEFORE_OUTCOMES`。

本补充在 CY-021 全市场物化期间、任何本研究线收益读取前登记。它不改变原协议的
效应门槛、样本期、向前折、置换次数、容量、成本或停止规则，只把三个模块的计算
公式和陈旧状态对照固定下来。

## 1. 共同量纲与可观测性

设决策日收盘为 `C_t`，14 日 ATR 为 `ATR_t`，语义筹码中位估计为三个卖方模型的
中位数。所有 20 日滞后均按该股票交易日序号计算，不按自然日。

只有同时满足以下条件的候选可进入筹码增量统计：

- CY-021 `research_valid=true`、`available_at <= decision_at`；
- CY-019 当日精确状态有效、质量守恒且主导带质量非空；
- `known_cost_fraction_min >= 0.95`；
- 上下价格峰及峰间谷均可观测；
- 三模型 I90 宽度分歧除以 `ATR_t/C_t` 不高于该向前折拟合期的 80% 分位数。

最后一项只作质量门，不作为收益方向因子；分位点只由拟合期测量值确定。

## 2. 三个模块的固定原始指标

### 集中支撑

- `i70_width_atr = (Q85_t - Q15_t) / ATR_t`，方向低为好；
- `i90_width_atr = (Q95_t - Q05_t) / ATR_t`，方向低为好；
- `dominant_band_mass` 直接取注册 CY-019 的精确主导带质量，方向高为好。

### 成本迁移

- `price_minus_cost_migration_20_vol = [momentum20_t -
  (Q50_t/Q50_{t-20}-1)] / (ATR_t/C_t)`，方向高为好；
- `profit_ratio_change_20 = profit_ratio_t - profit_ratio_{t-20}`，方向高为好；
- `i90_contraction_20 = i90_width_fraction_{t-20} -
  i90_width_fraction_t`，方向高为好。

### 上方压力化解

- `profit_ratio_t`，方向高为好；
- `upper_to_lower_peak_strength = upper_peak_strength /
  lower_peak_strength`，方向低为好；
- `valley_depth_t`，方向高为好。

Q50 只用于成本迁移中心，取 CY-019 三模型中位 `p50`；主导带质量同样取 CY-019，
不再新增可调峰宽。

## 3. 无权重学习的模块合成

每个向前折只在拟合期为每个原始指标建立经验分布。按预期方向把指标变成
`[0,1]` 好度百分位（低为好者取 `1-ECDF`，高为好者取 `ECDF`），三个指标等权平均
形成模块分数。禁止学习权重、删指标或按收益选择变换。

模块五分位边界只由拟合期模块分数确定，评价期和陈旧状态都使用相同边界。主要
对比是评价期最高五分位减最低五分位。

每个模块还必须满足至少两个原始指标各自最高/最低方向正确；否则即使合成分数偶然
通过也判失败。

## 4. 陈旧状态与安慰剂

陈旧对照把三个原始指标全部替换为 `t-20` 当时可得的对应值，但仍使用同一拟合期
经验变换和同一五分位边界。当前模块的评价期最高/最低收益差必须严格大于陈旧模块
的点估计；否则“筹码迁移具有及时性”失败。

199 次安慰剂只在信号 ISO 周、行业、市场状态、行业状态以及价格量特征五分位组成
的层内，以固定哈希种子置换当前模块分数；不得跨层打乱或重复选择最有利随机种子。
