# CYQ-GAME 首版数据源矩阵

本矩阵只描述首个可运行的 **PIT-B 因果研究版**。它不把当前快照冒充历史归档，也不让尚未物化的财务披露阻塞核心系统。机器准入仍以 `configs/data_asset_registry.json` 和激活 manifest 为准。

## 首版固定边界

- 必需硬域：日线/交易状态、行业成员、历史流通股本、公司行动、市场规则；任一未知即 `hard_valid=false`。
- 财务披露不是首版硬域，也不是首版 alpha。找到并冻结新数据后，先更新本矩阵和注册表，再单独晋级。
- CY-006 与 CY-008 是当前唯一已激活的组合输入；严格 PIT-A、实盘、L2 队列和真实参与者账户识别均不在首版声明范围。
- 采集器只有在发现新缺口时才运行；已有冻结文件优先做有界读取、断点续读和幂等校验，禁止无变化重复全市场下载。
