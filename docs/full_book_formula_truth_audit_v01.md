# 全书筹码公式真值审计（v0.1）

本审计把《筹码结构交易学》中的概念与当前可复现特征实现逐项对齐。结论不是“代码能运行”就等于“书中指标已经实现”：凡是定义、边界、时点或语义没有闭合的项目，严格研究输出一律标记为 `RESEARCH_CONDITIONAL`，不能写成策略有效。

## 总结结论

1. 当前质量链路具备较好的点时基础：每日数据、筹码特征、快照和 `available_at` 被保留，特征文件有 `mass_sum`，状态对象有精确质量守恒检查，交易扫描使用信号日后的下一可交易开盘成交。
2. 当前特征仍不能宣称是书中原样的“I90/I70”：代码字段只有 `p10/p90`，其含义是 Q10/Q90；书中 I90 的定义是 Q05–Q95，I70 是 Q15–Q85。因此现有 B1/B2/B6 等使用 `p90-p10` 的实验是明确的代理假设，不是严格复现。
3. `concentration_20` 是“任意相对价格宽度 20% 窗口的最大筹码质量”，不是书中固定唯一公式。它可以作为可检验代理，但必须在结果中单列，不能命名为“集中度已正确实现”。
4. `peaks_json` 当前按峰质量/质量排序，而不是按价格排序。`peaks_json[1]` 不必然是“上方峰”，所以用 `peak2_center > p50` 代表双峰上峰存在是不充分的。
5. `base_retention` 使用初始固定价格带的保留质量，是一个可复现代理；它没有自动等同于书中“低成本筹码保留”。书中语义需要明确低成本带、活动峰和迁移方向。
6. 当前 B/S 扫描的退出部分已有两个会显著改变结论的实现问题：部分 S2/S3 书中属于预警/减仓却被当成全清；部分动态条件误用了入场时的 `prev_*` 阈值；原扫描的退出收益使用确认日收盘价，语义重跑应使用确认后下一交易日开盘价。

## 逐项对照

| 书中要求 | 当前实现 | 点时/数据检查 | 状态 | 后续动作 |
|---|---|---|---|---|
| 筹码分布是持仓成本状态估计，不是庄家账户透视 | `ChipState.mass` 与年龄质量；没有真实账户字段 | 状态来自登记的数据资产；不可将峰解释为某类真实参与者 | 通过（认知约束） | 所有报告使用“参与者行为假设/替代解释” |
| 状态更新为旧筹码与当期成交分布的迁移 | `ChipEngine.update`/`advance_chip_state` | `mass_sum` 和 cohort 行质量在 `ChipState` 中检查 | 条件通过 | 运行全量质量审计，禁止归一化掩盖守恒错误 |
| I90 = Q05–Q95 | 只有 `p10`、`p90`，即 Q10/Q90 | 字段名与计算公式可核验 | 不通过严格复现 | 新增 `p05/p15/p85/p95` 或从原始状态重算；在此之前只叫代理带宽 |
| I70 = Q15–Q85 | 未实现 | 无对应字段 | 不通过 | 同上；保护止损和低成本带优先使用显式分位数 |
| 分位数边界/累计质量 | `searchsorted(..., side='left')`，CDF 为 `price <= threshold` | 边界行为应写入单元测试 | 条件通过 | 增加离散质量在边界的测试样例 |
| 集中度 | `concentration_20 = max mass([p, 1.2p])` | 窗口定义和归一化固定在代码 | 代理通过、书本严格定义不通过 | 报告注明“20%最大窗口质量”，与 I90/I70 分开 |
| 峰值质量 | 高斯平滑、局部极大、prominence、半高宽、质量 | `peaks_json` 保存中心/质量/宽度/prominence/年龄 | 条件通过 | 把排序语义显式化，同时产生“按价格上方峰”视图 |
| 主峰/上方峰/谷 | `[0]` 按质量排序；`[1]` 是第二大质量峰 | 第二大质量峰可能在下方 | 不通过严格上方峰语义 | 根据价格位置筛选候选峰，再定义主峰和上方峰；B3 重写 |
| 筹码迁移优先于静态形状 | 有 `average_cost`、峰变化、`base_retention` 等代理 | 迁移量不是单独质量流字段 | 条件通过 | 输出 Δ均价、低成本保留、峰质量迁移三类变化 |
| 低成本筹码保留 | 固定初始 p10–p90 带内的质量比 | 不是动态低成本带；且当前 p10/p90 非 I90 | 代理 | 使用显式 I70/I90 带，并同时保留固定基准作敏感性分析 |
| B1 低单峰收敛突破 | 有收窄、单峰、突破、成交量、低点过滤 | 缺少严格 1–3 日不回落确认；带宽为 Q10/Q90 | 不通过严格复现 | 加入回踩不回落时序和 I90 带版本 |
| B2 突破—缩量回踩—重新站回主峰 | 有回踩和重站回 `prev_p90` 代理 | 回踩连接、有效性和重站后保持需逐项验证 | 不通过严格复现 | 使用动态主峰/上峰、确认后成交，增加保持条件 |
| B3 双峰填谷/上峰突破 | 以第二大质量峰和 p50 交叉代理 | `peak2` 未必是价格上方峰；没有谷和上峰下沿 | 不通过严格复现 | 重建按价格排序峰、谷、上峰下沿 |
| B4 上行发散+低成本保留 | 有均价突破、上涨、缩量、保留质量 | 未显式抑制高位峰增长/价格停滞 | 代理 | 增加高位峰质量、均价与价格速度关系 |
| B5 洗盘后重站 | 有 p50 重站、缩量、保留和低点过滤 | p50 不是主峰/70%带；缺少重站后保持 | 不通过严格复现 | 使用动态带和下一日保持 |
| B6 历史密集区反转 | 有 p90、历史高位、放量、前期突破 | 没有明确历史成本带/下降趋势线；风险标签不完整 | 代理 | 单列高风险，不与普通突破混合晋级 |
| S1 主峰/关键带破坏 | 有连续跌破代理 | 原实现部分阈值固定为入场时滞后值 | 不通过 | 使用退出当时动态带和反抽失败确认 |
| S2 高峰扩张、价格停滞 | 有集中度/峰显著性条件 | 书中首先是预警/减仓，不应无条件清仓 | 不通过 | 作为 warning/reduction 与 full exit 分离 |
| S3 低成本保留坍缩 | 有保留率代理 | 书中要求新高成本带上方稳定、回踩有承接等确认 | 不通过 | 先 warning，确认失败后才 structural exit |
| S4 突破失败/单峰转双峰 | 有双峰、跌回 p50 | 动态峰/谷语义不完整 | 不通过 | 动态确认，跌回后下一交易日成交 |
| S5 缺口/大阴线灾难 | 有跌破 p10+放量阴线 | 缺少缺口、次日不能回补/收复主峰的条件 | 不通过 | 添加两日确认，保留灾难出口 |
| S6 下行发散/套牢峰 | 有 space/均价/峰代理 | 没有完整的反抽到成本带/谷位再失败 | 代理 | 加入反抽失败，保持硬风险出口 |
| 止损/保护 | 当前固定入场价 -8% | 不是书中移动保护结构 | 仅硬风险护栏 | 新增动态保护线；固定止损只作灾难兜底敏感性 |
| 触发后不可同柱成交 | 入口使用下一交易日开盘 | 旧退出事件收益曾使用确认柱收盘 | 旧结果不合格 | 语义重跑统一确认日信号、下一日开盘成交 |
| 大盘/行业环境 | 有大盘均线、行业 leave-one-out | 输入保留 PIT/快照 | 条件通过 | 继续按书中四门槛报告，不把环境门槛当筹码证据 |

## 研究含义

在严格修复前，旧网格的负收益不能直接证伪全书方法，因为它同时混合了：Q10/Q90 代理带、峰排序代理、静态退出阈值、预警当清仓和退出同柱收盘计价。修复后仍需在 2020–2022 发现集和 2023 锁定验证集上同时满足信号频率、净收益、回撤/尾部、板块分层和替代解释门槛；否则结论应是“当前可验证版本没有增量”，而不是继续调参。
