# CYQ-GAME 2020–2023 筹码交易规则研究冻结

冻结日期：2026-08-22
研究等级：PIT-B 因果研究版；不是 PIT-A 归档，也不授权实盘。

## 研究目标

在可追溯的筹码状态、筹码迁移、价格行为和大盘环境数据上，研究可执行的买点、卖点、持有期、止盈止损和市场环境过滤规则。所谓“庄家认知”只表示可检验的参与者行为假设，例如吸筹、派发、锁仓、套牢盘转移、诱多或诱空；不得解释为识别真实账户或真实庄家。

## 冻结样本

| 项目 | 冻结口径 |
|---|---|
| 研究区间 | 2020-01-02 至 2023-12-29，交易日收盘形成信号，次一可交易日开盘后才能成交 |
| 状态预热 | 使用 2018-01-02 起的可用历史；预热数据不计入研究收益 |
| 原始日线 | 5,247 个标的，4,400,570 行 |
| hard_valid 日线 | 5,008 个标的，4,214,257 行 |
| 生存者样本 | 2023-12-29 有 hard_valid 记录的 5,002 个非北交所标的 |
| 明确排除 | 北交所代码；2023-12-29 前已无有效记录的退市/失效标的 |
| 样本偏差 | 生存者偏差、退市标的排除偏差、PIT-B 供应商版本链不完整偏差；所有报告必须明确标注 |

生存者样本只用于研究样本筛选，不允许把 2023-12-29 的未来信息写入任何 2020–2023 的日内状态、筹码、信号或成交价格。每条输入记录仍必须满足 `available_at <= decision_at`，并保留 `snapshot_id`。

## 权威输入

本研究只允许使用 `configs/data_asset_registry.json` 中已登记且通过自身及交叉门禁的输入：

- `CY-006`：2018–2026 日线 PIT-B V2，含交易状态、流通股本、公司行动、市场规则和 PIT 字段。
- `CY-008`：2018–2026 分钟数据 PIT-B V2；首轮研究用于日内成交/执行特征和状态交叉核验，不用分钟数据伪造缺失的交易状态。
- `CY-009`：2018–2026 筹码状态 V2；只使用其严格有效状态，必须检查筹码守恒和状态连续性。
- `QD-003`：大盘及主要指数日线，用于市场环境过滤。
- `QD-001`、`QD-002`、`QD-008`、`QD-009`、`QD-010`：作为已登记的日线、状态、行业、流通股本和公司行动来源；若与 CY 物化结果冲突，记录冲突并阻断该记录，不能静默覆盖。

当前冻结数据审计已报告 coverage、重复、时间穿越、一致性和跨表检查通过；这不等于公司行动版本链已经达到 PIT-A。公司行动、流通股本和价格坐标仍须在生成筹码状态前验证。

## 研究前必须通过的准确性检查

1. 未复权 OHLC、成交量、成交额和原始换手率单位一致；复权只通过独立公司行动重建，不把供应商当前前复权列直接当作 PIT 事实。
2. 公司行动按公告/可用时间和生效时间因果连接；价格、筹码桶、获利比例、ASR/CYQ 特征使用同一价格坐标。
3. 流通股本按有效时间和可用时间连接；未知时该行不得进入严格筹码研究。
4. 筹码质量守恒：筹码总质量、转移账本和归一化前后质量逐行或按批次核对，归一化不得掩盖误差。
5. `CYQK_pre` 使用交易前状态；收盘形成的信号不得在同一根 K 线成交。
6. 分钟线只补充可观测的成交/停牌交叉证据；分钟线存在不等于日线状态一定有效。
7. 大盘环境只使用当时已经可用的指数记录；缺失或冲突时进入 `NO_TRADE`，不得猜测填补。

## 研究与验证分割

- 2020–2022：候选规则、参数和阈值探索。
- 2023：时间外验证，参数冻结后只运行一次正式验证。
- 任何候选规则必须和简单基线、随机/横截面基准及 `NO_TRADE` 比较，并计入手续费、滑点、冲击、涨跌停阻塞和不可成交尾部风险。
- 研究结论必须同时报告信号质量和可成交组合表现；“假设所有信号都能成交”只能作为独立的信号质量分析，不能冒充交易回测。

## 禁止事项

- 禁止用未来行业、公司行动、流通股本或退市后信息回填历史。
- 禁止在数据准确性门禁未通过前进行 2020–2023 正式回测。
- 禁止把重复全量计算、重复回测或旧运行结果当作本 goal 的进展。
- 禁止据此进入 2024–2026 最终回测或实盘。
