# CYQ semantic v2 artifact invalidation

All feature, panel, signal, label, backtest, calibration, selection, and
promotion artifacts produced before `cyq-semantic-epoch-20260825-v2` are
invalid inputs. They remain immutable audit evidence only.

The invalidation is caused by changes to cell identity, peak definition and
tracking, corporate-action coordinates, valid-chain windows, exact-lineage
states, frozen-ATR lifecycle comparisons, and next-legal-window labels.

An artifact is reusable only when its manifest contains the complete semantic
fingerprint returned by `semantic_fingerprint_fields()` and every value equals
the running code. Path existence, a legacy builder hash, or a matching old
strategy config is insufficient. Silent fallback to an older artifact is
forbidden.

No old performance, signal count, entry date, calibration, or promotion result
may be compared as if it were generated by the repaired semantics. The formal
before/after report must label the old side `INVALID_LEGACY_BASELINE` and build
the repaired side from registered raw inputs without derived-artifact reuse.
