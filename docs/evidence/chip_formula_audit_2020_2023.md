# 筹码特征公式与时序核验（2020–2023 探测基线）

## 结论

当前实现没有发现会整体反转信号方向的公式错误。分位点、获利盘/套牢盘互补关系、20% 成本窗和筹码峰向量化实现均已有单元测试；当前定向测试结果为 `10 passed`。

这不等于筹码估计器已经等同于真实持仓。日线无逐笔成本时使用价格分布近似，逐分钟数据则按观测成交价聚合到对数价格网格；两者都只能解释为带记忆和模型误差的成本状态估计。

## 逐项结果

| 项目 | 当前定义 | 核验结果 | 规则含义 |
|---|---|---|---|
| 分位点 | 质量和的离散左分位点，p01/p10/p50/p90/p99 | 单调性通过 | 不做线性插值；跨日比较必须使用同一状态版本/网格口径 |
| 获利盘 | `sum(mass[price <= close])` | 与 CDF 一致 | 收盘价相等的筹码计入获利盘 |
| 套牢盘 | `1 - profit_ratio` | 互补关系通过 | 不能据此推断真实投资者账户或庄家持仓 |
| ASR | `CDF(1.1*close)-CDF(0.9*close)` | 范围/质量审计通过 | 当前保存为 0–1 比例，不是百分数 |
| 集中度 | 所有起点 `[p, 1.2p]` 中的最大质量 | 与扫描参考实现一致 | 是右侧相对宽度窗口，不是对称价格区间 |
| 筹码峰 | 高斯平滑后局部峰、半高宽、峰内质量和、prominence | 向量化结果与参考实现一致 | 重叠峰不能相加解释总筹码；峰质量和可能重叠 |
| 基准筹码带 | 初始有效状态的 p10–p90；之后追踪该价格带质量保留率 | 代码时序可追溯 | 它是样本起点基准，不是每天重新选出的主峰 |

## 必须锁死的时序边界

`advance_chip_state` 对已有状态先计算 `CYQK_pre`，再用当日成交更新状态并计算其他收盘特征。因此：

1. `CYQK_pre` 可以作为当日交易前状态；
2. `profit_ratio`、分位点、集中度、峰等当前字段是当日更新后的收盘状态，只能用于下一交易日决策/执行；
3. 任何信号形成于 bar `t`，成交只能落在下一可交易 bar；不能用 bar `t` 的收盘后筹码在 bar `t` 内成交；
4. 回测查询必须同时核对 `available_at`、`snapshot_id`、`strict_sample` 和 `hard_valid`，不能因为数据文件存在就视作可用；
5. 交易前想使用成本结构，必须使用 `*_pre` 字段，或把信号决策时点明确设为收盘后、执行设为 `t+1`。

## 尚未证明的部分

公式通过只说明“实现与定义一致”，不能证明参数有效。接下来必须对 B1–B6 做条件消融：分别移除市场门、板块门、峰条件、筹码迁移条件、价格触发和成交量确认，观察每个条件对次日可成交收益、最大回撤、失败退出和信号密度的边际贡献；S1–S6 也要进行同样的逐项消融。
