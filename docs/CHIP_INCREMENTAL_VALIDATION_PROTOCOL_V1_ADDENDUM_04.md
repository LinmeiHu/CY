# 筹码增量价值协议 V1 勘误 04：可实现的时间广度门槛

状态：`PREREGISTERED_WEEK_BREADTH_CORRECTION_BEFORE_OUTCOMES`。

本勘误只统计价格量候选的日期，不读取收益、成交结果或 2023 数据。两个预注册评价
区间内候选事件分别覆盖 42 周和 28 周，合计只有 70 个不同 ISO 周。原“至少 104
个不同信号周”因此在数学上不可能通过，不能区分筹码有效与无效。

将该单一门槛替换为：两个评价折合计至少 52 个不同 ISO 周，且每个评价折至少 20
周。52 周代表至少一整年的等价时间广度，每折 20 周防止证据全部来自一年。候选
产生于预注册的非弱市场/行业状态，本就不应要求覆盖无信号的风险关闭周。

以下门槛完全不变：有效样本至少 396、两折收益差均为正、周聚类 10,000 次
bootstrap、95% 下界大于 0、区间半宽不超过 1%、效应至少 1%、单调性、199 次
安慰剂、Holm 5%、容量与及时性对照。不得在收益读取后再次修改周数。
