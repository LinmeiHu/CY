# 筹码增量价值协议 V1 勘误 05：公司行动坐标与安慰剂可识别性

状态：`PREREGISTERED_IDENTIFIABILITY_CORRECTION_BEFORE_OUTCOMES`。

本勘误来自首次收益读取前的协议—实现审计。审计没有读取收益、成交结果或 2023
数据，也不改变任何筹码方向、效应、成本、向前折、置换次数或多重检验门槛。

## 1. 成本迁移使用公司行动中性的经济坐标

原始日线价格坐标会因拆并股和现金分红机械变化。若直接比较 `Q50_t` 与
`Q50_{t-20}`，跨除权窗口会把机械再定标误当成筹码成本迁移。

对每只股票从已注册的日线起点开始，仅用当日可得的 `share_multiplier=m_t` 和
`cash_per_share=c_t` 递推：

- `M_t = product(m_j, j <= t)`；
- `B_t = sum(c_j * M_{j-1}, j <= t)`；
- `economic_Q50_t = raw_Q50_t * M_t + B_t`。

成本迁移模块中的当前、20 日和 40 日 Q50 全部使用该经济坐标。拆股会由 `M_t`
抵消，现金分红会由 `B_t` 抵消；同日之后才可得的公司行动不得进入此前记录。
其他固定原始指标不变。

## 2. 受限置换必须具有足够的有效交换支持

勘误 03 已规定未配对行保持不变，并写明可交换覆盖不足时结论只能是
`INSUFFICIENT_EVIDENCE`，但未把“覆盖不足”数值化。现固定如下，不得在读取收益后
修改：

1. `informative pair` 指交换模块分数后，至少一行的最高/最低拟合期五分位归属会
   改变；同五分位互换和只在中间五分位内互换不计。
2. informative pair 涉及的不同评价行至少 396 行。
3. informative pair 合计覆盖至少 52 个不同 ISO 周，且每个向前评价折至少覆盖
   20 周。
4. 任一门槛不满足，该模块为 `INSUFFICIENT_EVIDENCE`；不得把它解释为筹码无效，
   也不得放宽匹配、跨周/行业置换或追加随机种子。

396、52 和每折 20 分别沿用既有有效样本与时间广度门槛，因此没有新增可调自由度。
199 次置换、真实统计量超过 99% 分位和 Holm 5% 均保持不变。
